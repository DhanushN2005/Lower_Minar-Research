# 📊 Lower Minar Research  
**Statistical Analysis of Water Parameters**

This repository contains a **data science research project** focused on the statistical analysis of water quality parameters.  
The main artifact in this project is a Jupyter Notebook that explores and analyzes water quality data to extract insights and trends.

---

## 🔍 Project Overview

Water quality is a key factor in environmental and public health studies.  
This project aims to:

✔ Explore water parameters using statistical methods  
✔ Visualize trends, correlations, and distributions  
✔ Report insights that can support decision-making or further research

The analysis is presented in a Jupyter Notebook (`Stastical_analysis of water parameters.ipynb`) with visualizations and descriptive statistics. :contentReference[oaicite:1]{index=1}
